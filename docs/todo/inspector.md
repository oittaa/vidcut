# Inspector

**When:** not decided.

The Inspector tab shows and sets the transform, the crop, the Dynamic Zoom and the opacity of the selected clips ([deviation X70](../deviations.md#x70-the-inspector-is-a-tab-beside-the-media-pool-in-frame-pixels)).
Its Speed section sets the speed of the selected clips. Its Audio section sets the Volume, the Mute and the Voice Isolation of the selected clips with sound.
It also shows the open title, subtitle and subtitle track. These parts are still to do.

- **The composite modes.**
  - Now: the Composite section has Opacity only (§8.15).
  - Why: Resolve's Composite has a mode that mixes the clip with the tracks below in other ways (p. 769).
