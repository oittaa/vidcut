# Cut-page behavior that vidcut does not have

What [the spec](../cut-page-spec.md) describes and vidcut does not do.

- Metadata view: Date Created, Scene, Shot, Take, Comment, and the clusters and main descriptions that use them ([§3](../cut-page-spec.md#3-media-pool-ch-34-pp-653675))
- Sort orders of pp. 662–663: Camera, Date Time, Bin, Scene Shot, Clip Color, Online Status ([§3](../cut-page-spec.md#3-media-pool-ch-34-pp-653675))
- Zoom of the waveform in the Source Clip scroll area, once measured ([§4.1](../cut-page-spec.md#41-modes))
- Menu commands Trim > Roll > Start to Playhead and End to Playhead ([§8.6](../cut-page-spec.md#86-trimming-pp-693-716-718-726732))
- Transcription window: Create Subclip, and a marker on a source clip ([§8.13](../cut-page-spec.md#813-text-based-editing-pp-714-9941009))
