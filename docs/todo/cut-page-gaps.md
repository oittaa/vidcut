# Cut-page behavior that vidcut does not have

What [the spec](../cut-page-spec.md) describes and vidcut does not do.

- Date Imported clusters by day: vidcut keeps no date of import ([§3](../cut-page-spec.md#3-media-pool-ch-34-pp-653675))
- Zoom of the waveform in the Source Clip scroll area, once measured ([§4.1](../cut-page-spec.md#41-modes))
- Audio Assistant, Voice Convert, Set Color and Add Marker, and Add Transition to All Edits in Timeline Actions ([§2](../cut-page-spec.md#2-layout-pp-636637))
- Most of the System and User preferences (p. 94)
- Deinterlace Quality for each clip (Normal, High, Neural Engine), and the deinterlace switch of Clip Attributes (pp. 741, 451)
- The Use proxy media setting of an export (p. 214)
- CEA-608 and EAS708 captions, and MXF files (pp. 1247–1248)
- Export and import of a subtitle preset as a `.preset` file (pp. 1239–1240)
- KeyKode in the timecode menu of the viewer (pp. 713–714)
- A render cache with alpha in DNxHR 444 and in the uncompressed formats (p. 201)
