- EXR file names for a source whose name ends in a digit.
- Use unique filenames together with Source name.
- EXR together with Source name, File suffix, Use unique filenames, or Add source frame count off.
- After head for Preserve on a path with no drive letter.
- Replace existing files in place with an image-sequence source.
- Individual clips that render at the frame rate of each clip.
- Render timeline effects and Render at source resolution for Individual clips.
- The Preserved Path row.
- Use commercial workflow and its rows.
- For Single clip: Filename uses Timeline name, File suffix, File subfolder, Render without timecode and Start timeline timecode at.
