# A dB scale beside the Mixer's faders

**When:** next.

Each fader is a bare vertical slider from −60 to +24 dB, with only its current value printed beside it. A level can't be read off a fader's position, and 0 dB is hard to find.

- Beside every fader, a scale with dB numbers (such as +24, +12, +6, 0, −6, −12, −24, −60).
- 0 dB clearly marked: a longer tick or a line across the fader, easy to set by eye.
- The meters beside the faders have no scale either (−60 to 0 dBFS); one would help there too.
