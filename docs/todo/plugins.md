# Plugins

- OpenFX picture plugins.
- Audio plugins: VST3 on Windows and macOS, and Audio Units on macOS.
- An audio plugin format on Linux.
- The installed plugins in the Effects tab, in their own categories.
- The Open FX and the Audio FX of a clip in the Effects panel of the Inspector.
- Open FX before the clip grade in the picture order.
- The place of the Audio FX among the sound tools of a clip.
- The Video Plugins and Audio Plugins preferences: each plugin on or off, and the plugin folders.
- A plugin that crashed or hung at the last start stays off until the user turns it on.
- A plugin crash that does not close vidcut or damage the project.
- A project that stores each plugin and its values, and opens when a plugin is missing.
- Plugin values that the CLI, IPC and MCP read and set.
- The window of a plugin.
- Plugins in OpenTimelineIO files.
- The same plugin result in the viewer and in the export.
