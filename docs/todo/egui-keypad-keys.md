# egui: the keys of the numeric keypad

- Keys of the numeric keypad apart from the keys of the main keyboard.
- Keypad keys for the Full and Quarter printer points, and the Printer Light Hotkeys item.
- Num+= for Go to a Timecode, Num++ for Jump Forward and Num+- for Jump Back.
- Keypad keys in the built-in key sets of other editors.
