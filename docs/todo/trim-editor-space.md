# Space in the Trim Editor

**When:** on the Windows computer, with the dissolve checks ([dissolve-placement.md](dissolve-placement.md)).

In vidcut, Space starts the timeline player while the Trim Editor keeps showing its two still pictures, so the sound plays and the playhead moves but no picture does. The manual doesn't say what Space does there. Check Resolve's Cut page, then make vidcut do the same:

1. Double-click a cut between two clips.
2. Press Space.
3. Note whether the viewer plays the timeline, plays around the cut, or closes the Trim Editor, and where it stops.
4. Press Space again, and note whether the Trim Editor comes back.

If Resolve plays around the cut, the rule is Dynamic Trim's (spec D32), shared.
