# To do

Open work, **one file per item**. The files in this folder are the list: there is no index to keep up to date.

- **New work:** add a file named after it (`render-queue.md`): what it is, why, and anything known about how.
- **Finished work:** delete its file in the pull request that finishes it, and describe the result where the behavior is documented (the spec, a decision record, AGENTS.md).
- **Work in progress:** name the pull request in the item's file.

Pull requests that touch different items change different files, so they never conflict over this list.

Smaller Cut-page features not built yet are marked **(later)** in [the spec](../cut-page-spec.md), next to the behavior they belong to.
