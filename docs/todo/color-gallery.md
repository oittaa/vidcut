# The Gallery, stills, groups and Apply Grade

## Stills and Apply Grade

- The ID of a still from the track and the place of the clip, as Resolve gives it.
- Change Label, and a double-click under the ID.
- Apply Grades Using, and Apply Grade of a still whose grade has keyframes.
- Apply Active Layer.
- A drag of a still into the viewer.
- A Shift-click that selects a range of stills.
- A click on a covered clip in the Thumbnail timeline does not make it the current clip.
- Some Thumbnail timeline selection cases: not checked against Resolve.

## Albums and Memories

- Still albums: add, rename, remove, and a drag of a still onto an album.
- Memories A to H: save, load, clear and the drags.

## Copy options

- Preserve number of nodes.
- Append Node Graph, from the menu and from a drop onto a link.
- Apply Grade From One Clip Prior and From Two Clips Prior.
- Copy and paste of the whole grade on the Thumbnail timeline.
- Preview Memory.
- Align Keyframes to Current Frame.
- Ripple Node Changes to Selected Clips.
- Append Node to Selected Clips.

## Groups

- Color groups with a Pre-Clip grade and a Post-Clip grade.
- The Group Pre-Clip and Group Post-Clip modes of the Node Editor.
- The group items and the group badge on the Thumbnail timeline.
- Color groups in OTIO files.
- Collapse Group Grades.
- The Grouped filter with each group and Current Group.
- Post Group Node Stack Layer.
- Ripple Node Changes to Current Group.

## Wipes

- Image Wipe, Play Still, Next Still and Previous Still.
- The wipe styles, Invert Wipe and a drag of the wipe.
- The Reference Wipe Modes and Wipe Timeline Clip.
- Match Reference Wipe Frame.
- The Split Screen modes.

## Shared nodes

- Save as Shared Node, the Add Node entries, Convert to Corrector and Delete Shared Node.

## Gallery tools

- The Timelines album and Copy Active Layer.
- The Display Node Graph window and its Apply buttons.
- Import and Export of stills, with DRX files and the still picture formats.
- PowerGrade albums that all projects share.
- Automatic labels, Sort Stills, List View, Search, Still Size and Properties.
- Grab All Stills, Grab Missing Stills, Trace Timeline, One Still Per Scene and Show Current Timeline Only.
- Apply Display LUT, Show All Stills and Use labels on still export.
- Live Preview and Hover Scrub Preview.
- The Gallery window with the stills of other projects.
