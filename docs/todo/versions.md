# Grade versions

- More than one grade version for each clip.
- Local versions and remote versions.
- The project setting "Use local version for new clips in timeline".
- Add, Create New Version, Load, Rename, Delete and Copy to Local for a version.
- Default, which loads Version 1.
- Delete All Versions and Delete Unused Versions.
- Use Local Grades, Use Remote Grades, Copy Remote Grades to Local and Copy Local Grades to Remote.
- Preset names for versions in the Project Settings.
- Versions of the Pre-Clip and Post-Clip grades of a group.
- The split screens Versions and Versions and Original.
- The timeline filter Common Media Pool Clips.
- Render Disabled and Enable Flat Pass in the commercial workflow output.
